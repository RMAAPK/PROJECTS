## 🚀 Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build & Run Production Web Service
```bash
npm run build
npm start
```

---

## ☁️ Deploying to Render Web Services

1. Connect this GitHub repository (`alicncltd/ceopw`) to **Render**.
2. Create a new **Web Service**.
3. Render will automatically detect [`render.yaml`](./render.yaml):
   - **Environment:** `Node`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/healthz`
4. Set your custom domain (e.g. `rmaa.pk`) in the Render Dashboard.
